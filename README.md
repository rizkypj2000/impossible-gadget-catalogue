A zero-dependency Node renderer that paints a studio catalogue photo of the NIMBUS LEASH: a glossy handheld leash whose taut cord tethers a small raincloud that waters exactly one potted succulent. It rasterizes everything procedurally and encodes the PNG by hand.

## Run it

```sh
node main.ts out/entry.png
```
